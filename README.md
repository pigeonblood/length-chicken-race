# ○○長さチキンレース！

隠された画像の「長さ」を予想し、ギリギリを攻めるパーティーゲームです。
HTML / CSS / JavaScript だけで動くので、GitHub Pages にそのまま置けば遊べます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み（ホーム / 回答者登録 / 問題設定 / 出題） |
| `style.css` | デザイン |
| `app.js` | ゲームの処理 |
| `favicon.svg` | タブのアイコン |

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`nagasa-chicken-race`、Public）
2. リポジトリのページで **Add file → Upload files** を選び、上の4ファイルをドラッグして **Commit changes**
3. **Settings → Pages** を開き、**Source** を「Deploy from a branch」、**Branch** を `main` / `/(root)` にして **Save**
4. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

ローカルで試すときは、フォルダ内で `python3 -m http.server` を実行して `http://localhost:8000` を開いてください（`index.html` をダブルクリックで開いても動きます）。

## 遊び方

1. **回答者を登録する**：名前を追加（最大12人）。色は自動で割り当て、色アイコンをタップで変更、▲▼で順番を入れ替え。
2. **スタート** → 問題設定
   - 「画像をインポート」で画像を選択（スマホは写真、PCはファイル。PCはドラッグ＆ドロップも可）
   - 矢印で「開いていく向き」を選ぶ（初期値は →）
   - 緑の「スタート」ライン（初期 2 割）より先が隠されます。赤の「正解」ライン（初期 8 割）が本当の端。どちらもドラッグで調整できます
   - お題（例：魚）を入れると、タイトルが「魚長さチキンレース！」になります
3. **出題** → 予想ターン：回答者が順番に画像をタップして予想位置を置き、ドラッグで微調整して「決定」
4. **チキンレース**：一巡したら、各自「伸ばす」か「降りる」を選択
   - 伸ばす：前の予想より長い位置にだけ動かせます
   - 降りる：予想が確定し、以降はスキップ
   - 全員が降りると「回答発表」ボタンが出ます
5. **回答発表**：マスクが少しずつ開き、正解ラインが表示されます
   - 正解ラインを超えた予想 → ✕ ドボン
   - 超えなかった予想のうち、いちばん正解に近い人 → ◯ 勝利で +1pt（同じ位置で並んだ場合は全員 +1pt）
6. 「ホームに戻る」でポイントを引き継いで次の問題へ

## 補足

- 回答者とポイントはブラウザ（localStorage）に保存されます。同じ端末・同じブラウザならページを閉じても残ります。
- 画像はブラウザの中だけで扱い、どこにもアップロードされません。
- 右上のスピーカーボタンで効果音のオン/オフを切り替えられます。
- ゲーム途中で ✕ を押すと「続ける / 問題設定に戻る / ホームに戻る」を選べます（問題設定に戻ると画像とラインはそのまま残ります）。
